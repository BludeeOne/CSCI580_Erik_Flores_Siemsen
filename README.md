## Assignment 4: Simulated Annealing and Genetic Algorithms

This assignment solves the Traveling Salesperson Problem (TSP) using Simulated Annealing (SA) and a Genetic Algorithm (GA), then compares both methods with a nearest-neighbor baseline.

### Results
For the recorded run, nearest neighbor produced a tour length of 6.0214, SA produced 5.0057, and GA produced 5.3672. See the technical report and notebook outputs for the full analysis.
